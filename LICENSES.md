# Licensing status

Public visibility is not a blanket redistribution license.

Before launch, the owner must choose explicit licenses for repository documentation and examples, editor binaries, and any official assets distributed with them. No open-source license for the game or editor is granted by this scaffold.

Every catalog entry must name the package license and link its full terms. Third-party dependencies retain their own licenses. Releases must include applicable license texts and third-party notices. Do not list a package whose redistribution permission is unknown.
